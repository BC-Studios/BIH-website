# Sansara Research Journal

Editorial workspace for Sansara's long-form research essays.

These pieces should be treated as research essays, not blog posts. The goal is a knowledge library with consistent article architecture, traceable references, and a premium reading experience.

## Workspace Map

- `content/research/` - publishable essay drafts and templates.
- `content/library/` - source library, researchers, glossary, and timelines.
- `editorial/` - positioning, style rules, and production workflow.

## Recommended Flow

1. Paste raw notes into a new essay file copied from `content/research/_essay-template.md`.
2. Add all papers, books, and talks to `content/library/references.csv`.
3. Add featured scientists to `content/library/researchers.csv`.
4. Build the chronological story before polishing prose.
5. Draft the movement-design implications.
6. Finish each essay with Open Questions.
