# Design System — Brain Innovation House x Sansara

## Brand Essence
Premium science x wellness. Intelligent, sensory, grounded. Where neuroscience meets embodied experience.

## Color Palette
```
--color-bg:        #05060f        /* deep space navy */
--color-surface:   #0d0f1e        /* dark navy surface */
--color-surface2:  #141629        /* card surface */
--color-border:    rgba(255,255,255,0.08)
--color-gold:      #c8a96e        /* soft warm gold */
--color-gold-dim:  rgba(200,169,110,0.15)
--color-violet:    #7c5cbf        /* electric violet */

--color-blue-dim:  rgba(79,142,247,0.12)
```

## Typography
- Display: "Cormorant Garamond" — editorial, elegant
- Body: "DM Sans" — clean, modern
- Mono/label: "DM Mono" — for tags and labels

## Layout
- Max content width: 1200px
- Section padding: 120px vertical
- Generous whitespace, asymmetric grid
- Neural/light-field SVG backgrounds (subtle, layered)

## Style Notes
- Dark backgrounds with layered gradient meshes
- Glowing borders / aurora edges on cards
- Staggered entrance animations on scroll
- No medical claims
- Tone: intelligent, sensory, grounded
