# Web Crosslinking Plan

The website should not present the essays as isolated posts. It should present them as a living research system.

## Page-Level Link Elements

Each article page should include:

- Issue position: `Essay 4 of 12`
- Act label: `Act II - The Brain as a Predictive Organism`
- Previous article
- Next article
- Builds on
- Continues in
- Concept threads
- Public themes
- Sensory map nodes
- Related companion essays
- Researchers featured
- Open questions
- Source library links

## Navigation Model

### Linear Reading

For readers who want the book-like path:

1. Previous article
2. Current article
3. Next article

### Conceptual Reading

For readers following an idea:

- Predictive processing
- Attention
- Rhythm
- Light
- Sensory coherence
- Flow
- State engineering
- Measurement

### Theme Reading

For readers entering through a familiar experience rather than a theory:

- Rhythm & Entrainment
- Flow State
- Breath & Nervous System
- Light & Perception
- Music & Emotion

These should work as reader pathways on the research index and as permanent theme pages under `/research/themes/`. The theme pages should gather issue essays first, then companion essays.

### Sensory Map Reading

For readers following the experience system underneath the themes:

- light -> circadian rhythm -> arousal / recovery -> attention quality -> flow
- rhythm -> entrainment -> movement fluency -> synchrony
- breath -> autonomic regulation -> calm / readiness
- sound -> emotion -> shared attention / awe
- space -> prediction load -> ease / coherence

These nodes should come from `articles/sensory-map.csv`. Article pages should show a compact sensory map block, and theme pages should show a sensory fingerprint.

### Research Lineage

For readers following scientists:

- Ulrich -> Kaplan -> Friston -> Clark -> Zeki -> Chatterjee
- Berson -> Foster -> Panda -> CIE -> Lucas
- Thaut -> Pranjic / Janzen -> motor timing
- Csikszentmihalyi -> Kounios / Rosen -> Swann / Sawyer
- Vickers -> Krakauer -> Davids
