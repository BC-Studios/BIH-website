# Sensory Map

The sensory map is the deeper structure underneath the public tags. Tags help readers enter the research through familiar themes. The sensory map explains which variables shape experience, which biological or cognitive systems they touch, and which states they help produce.

## Working Model

| Layer | Role | Example |
| --- | --- | --- |
| Public tags | Reader-facing pathways through the research. | Light & Perception; Rhythm & Entrainment; Breath & Nervous System |
| Sensory dimensions | The design variables that shape embodied experience. | light timing; tempo; breath cadence; acoustic texture; spatial order |
| Linked systems | The biological, cognitive, or social systems affected by sensory dimensions. | circadian rhythm; autonomic regulation; prediction; attention; synchrony |
| State outcomes | The states Sansara is trying to understand or design. | readiness; recovery; calm; awe; flow; collective coherence |

## Editorial Rule

Do not turn every sensory node into a public tag. Public tags should stay simple. The sensory map can be more precise, more causal, and more useful for internal editorial planning.

The public should feel:

- clear routes into the work;
- meaningful cross-links between articles;
- a sense that light, rhythm, breath, music, space, and flow belong to one system.

The editorial team should see:

- which sensory variables each article covers;
- which state outcomes are underdeveloped;
- which tags are too broad or too thin;
- which future essays would strengthen the research system.

## Corrected Light Pathway

Light should not be framed primarily as an attention switch. The stronger biological bridge is circadian rhythm.

Use this chain:

```text
light -> circadian rhythm -> arousal / recovery -> attention quality -> flow
```

This keeps `Light & Perception` grounded in timing, biology, readiness, visual comfort, and recovery rather than reducing it to a generic attention effect.

## How Tags And Map Nodes Interlink

Each tag page should include a sensory fingerprint:

```text
Tag: Rhythm & Entrainment
Sensory fingerprint: tempo; pulse; cadence; repetition; transitions; group rhythm
Linked systems: entrainment; motor timing; prediction; synchrony
State outcomes: movement fluency; collective flow; reduced effort; shared attention
Neighboring tags: Music & Emotion; Flow State; Breath & Nervous System
```

Each article page should include a compact sensory map block:

```text
Primary sensory axis: rhythm
Secondary axes: sound; attention; social field
Linked systems: entrainment; motor timing; prediction
State outcomes: synchrony; flow; movement fluency
```

## Website Implication

The website should support three kinds of movement:

| Reader intent | Navigation element |
| --- | --- |
| Read the series in order | previous / next article links |
| Follow a public theme | tag pages and filter chips |
| Follow the experience system | sensory map nodes and sensory fingerprints |

`Sensory Coherence` should be the concept hub that explains why the dimensions belong together. It should not compete with the five public tags.
